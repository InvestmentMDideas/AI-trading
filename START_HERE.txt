Issue: "Cannot connect to IBKR"
Fix: Make sure TWS or IB Gateway is running on port 7497

Issue: "No data available"
Fix: Market might be closed, or symbol is invalid

Issue: "Import errors"
Fix: Run: pip install -r requirements.txt

Issue: "Tests failing"
Fix: Run setup_check.py first to diagnose
