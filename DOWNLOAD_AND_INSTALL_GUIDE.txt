┌───────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: SETUP IBKR (Optional but Recommended)                                │
└───────────────────────────────────────────────────────────────────────────────┘

1. Start TWS or IB Gateway
2. Go to: File → Global Configuration → API → Settings
3. Enable:
   ✅ Enable ActiveX and Socket Clients
   ✅ Allow connections from localhost
   ✅ Read-Only API
4. Set Socket Port: 7497
5. Click OK and restart TWS/IB Gateway

⚠️  System works WITHOUT IBKR but with limited data!


┌───────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: SETUP OLLAMA (Optional but Recommended)                              │
└───────────────────────────────────────────────────────────────────────────────┘

1. Download Ollama from: https://ollama.com/download
2. Install it
3. Open terminal and run:
   ollama pull qwen2.5:7b
4. Wait for download (might take 5-10 minutes)
5. Verify: ollama list
   You should see qwen2.5:7b in the list

⚠️  System works WITHOUT OLLAMA but AI features will be disabled!

┌───────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING COMMON ISSUES                                                │
└───────────────────────────────────────────────────────────────────────────────┘

❌ "ModuleNotFoundError: No module named 'dash'"
   Fix: pip install dash dash-bootstrap-components plotly

❌ "ModuleNotFoundError: No module named 'paper_trading_engine'"
   Fix: Make sure paper_trading_engine.py is in the same folder

❌ "IBKR Connection Failed"
   Fix: Start TWS/IB Gateway OR system will run with limited features

❌ "Ollama not running"
   Fix: Start Ollama with 'ollama serve' OR system will run without AI

❌ "Port 8052 already in use"
   Fix: Kill process using port 8052 OR change port in code

❌ "Permission denied"
   Fix: Run as administrator (Windows) OR use sudo (Mac/Linux)

❌ "Dashboard shows 'Waiting for data'"
   Fix: Wait 5-10 seconds for first update OR check IBKR connection
